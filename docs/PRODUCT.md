# PRODUCT.md — Autexa (маркетинговый сайт)

## Register

brand — лендинг (autexa.pw: главная, /f/:slug, /tarify, /voprosy) продаёт SaaS; дизайн — часть продукта. Само приложение (веб-версия за логином, iOS/Android) — отдельный register: product; этот файл про сайт.

## Product

Autexa — система управления автосервисом: касса/заказ-наряды, склад, зарплата, клиенты, рассрочка, отчёты. Один backend, клиенты iPhone/Android/веб. Продаётся владельцам автосервисов в России (1–20 мастеров), канал заявок — WhatsApp/Telegram (+7 988 444-44-36), самообслуживания-регистрации нет.

## Target users

- **Владелец автосервиса** (главный покупатель): 30–55, Android/iPhone, часто только мобильный интернет. Боли: наличные «испаряются», всё держится на нём, учёт в тетради/Excel, не может отойти от сервиса.
- **Администратор**: скорость оформления, записи, поиск клиента.
- **Мастер**: своя выручка и зарплата на виду.

## Brand personality

Честный, конкретный, «свой» для гаражного бизнеса. Прямые заголовки в стиле обложки владельца («Программа для автосервиса: касса, склад, зарплата»), никакого канцелярита и англицизмов. Каждое обещание сверяется с кодом продукта — переобещания запрещены (список запретов в docs/ ниже).

## Anti-references (решения владельца, не нарушать)

- Тёмный полноэкранный hero — ОТВЕРГНУТ владельцем («текст не в тему, картинка тёмная»). Только светлая тема.
- AI-фиолетовые градиенты — запрещены (зачищены).
- «Написать» в нижнем баре — отвергнута; контакт живёт в шторке «Разделы», футере и CTA-секциях.
- Длинный текстовый скролл на мобиле — отвергнут; карусели/чипы/отдельные страницы.
- НЕ обещать: эквайринг Т-Банка (заглушка), Excel-экспорт отчётов, «уже в App Store», цены кроме реальных (Личный 1000 ₽ / Бизнес 7000 ₽ / Легенда 10000 ₽ + внедрение 100 000 ₽).

## Strategic principles

1. Mobile-first: покупатель приходит с телефона по ссылке из WhatsApp.
2. Психология продаж: боль → решение → выгоды по ролям → риск-реверс → CTA-мостик.
3. Честность конвертирует лучше глянца: реальные цены, реальные функции, свои скриншото-подобные мокапы и сгенерированные владельцем фото.
4. Google-CDN запрещён (операторы РФ режут): шрифты и ассеты — self-hosted.
5. Тексты — единый источник frontend/src/pages/landing/content.ts.
