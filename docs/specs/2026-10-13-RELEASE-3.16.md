# Autexa 3.16.0: приёмка выпуска

Реализация принята; публикация, нативные артефакты и решения Apple фиксируются отдельно в приватном release-state.json.

## Поведение

В выпуск входят принятые стартовые каталоги и фиксированная оплата мастеру, новый журнал с серверными комбинированными фильтрами, оформление и пошаговая онлайн-запись. Фильтр сотрудника использует только основного мастера чека; суммы — итог после скидки. Публичные изображения проходят декодирование и повторное кодирование в raster WebP с изоляцией автосервиса и филиала. Сохранённые повторы заявок не меняются.

Вход на сайте и телефонах: «Система управления автосервисами», «Зарегистрироваться». На iOS открывается существующая модерируемая заявка. Оплата и права не меняются. Проценка отложена.

## Проверки

- Интегрированный backend typecheck: 832 PASS, 53 SKIP, 0 FAIL; реальные PostgreSQL-сценарии онлайн-записи включены.
- Дополнительный реальный PostgreSQL/RLS журнала: 5/5 PASS.
- Mobile typecheck с critical checks: 262 + 10 PASS. Журнал и persistent cache: 54/54 PASS.
- Frontend production build прошёл; независимый Chrome с API fixtures и production preview: 13/13 сценариев и 3/3 компонентных race-проверок.
- Astra Max: независимое целевое критическое ревью без открытых замечаний. Исправлено и покрыто регрессиями искажение контакта при вставке телефона: 5/5 PASS.
- iOS 26.5 Simulator, реальный JS в ранее установленном debug host, синтетический контекст: вход, открытие регистрации, выбор сотрудника, суммы/скидка и экранная клавиатура. Исправлен отступ кнопки от клавиатуры в pageSheet.
- На 320 px исправлены переносы управления изображением. Публичная страница остаётся светлой, reduced motion отключает салют, повтор статуса не создаёт повторную отправку.

Android Emulator не удалось запустить: первый запуск завершился с кодом139, повтор с software GPU остановился на crash dialog. Это ограничение среды, а не PASS нативного Android GUI. Отдельные iOS/Android JS exports прошли у исполнителя; финальные EAS артефакты проверяются по пакету, версии, runtime, каналу и исходному commit.

## Выпуск

Пользователь разрешил сайт/backend, финальный APK и одну iOS-сборку для внешнего TestFlight и обновления App Store. App Store version3.16.0 создана, RU What’s New: «Исправлены ошибки и улучшена стабильность работы.» Наследованные скриншоты и сведения для проверки Apple доступны. Отправка не считается одобрением. Дополнительные платные сборки без новой причины не запускаются.
