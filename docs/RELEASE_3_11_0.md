# Autexa 3.11.0 — исправления и пилот обмена

## Изменения для пользователей

- В веб-формах и мобильной форме расходов ввод текста больше не пересоздаёт
  активное поле после каждой буквы.
- Заказ поставщику загружает весь каталог и открывает товары через привычные
  папки кассы. Исправлены обрезка каталога до первой тысячи и сравнение путей
  с пробелами вокруг `/`. Данные склада не переписываются.
- Кабинеты менеджера платформы и суперадмина корректно выбираются при входе;
  устаревший признак входа под клиентом не открывает менеджеру кассу мастера.
  Формы учитывают безопасные области экрана и клавиатуру.
- Журнал действий открывается из карточки конкретного автосервиса. Менеджер
  видит журналы только своих клиентов; общий журнал из вкладки «Ещё» убран.
- Награды и уведомления о зарплатах/авансах прокручиваются на маленьком экране,
  крупные символы и суммы имеют достаточную высоту строки. Суммы сохраняют копейки.
- Получатель штрафа видит отдельное уведомление с грустной анимацией, без
  праздничных конфетти. Повторный показ и подтверждение привязаны к сотруднику;
  исторические штрафы при обновлении не показываются заново.

## 1С: состояние пилота

Добавлены настройки, журнал, ключ подключения, API обмена и локальный транспорт.
По умолчанию обмен выключен. Изменения проходят штатные операции учёта,
повторные события учитываются, спорные версии попадают на сверку.

**Полноценная интеграция с реальной 1С пока не завершена:** нет тестовой базы
и проверенного адаптера конкретной конфигурации УНФ. Контракт и точные условия
подключения описаны в [инструкции](../integrations/one-c/README.md).
Эту часть нельзя считать проверенной по результатам локальных тестов транспорта.

## Выпуск

Backend должен обновиться до установки новой мобильной версии: нужны миграции
174/175, API журнала автосервиса и уведомлений о штрафах. Миграция175 помечает
старые штрафы просмотренными; новые остаются непросмотренными до подтверждения.
Уже применённые миграции не изменены.

Версия приложения —3.11.0, номера сборок выдаёт EAS автоматически. Платные
сборки EAS разрешены владельцем только для итогового релиза; локальные проверки
и симулятор выполняются до запуска этих сборок. Публикация iOS — во внешнюю
группу TestFlight «Autexa beta», Android — APK профиля preview.

До выкладки требуется проверенная резервная копия с VDS-хоста. Штатные
backup/restore-скрипты имеют ранее найденные ограничения проверки ошибок;
для этого выпуска используется отдельный проверенный архив, не перезаписываемый
штатным backup. На сервере сохраняются существующие локальные файлы окружения.

Результаты финального QA, ссылки на сборки и факт выкладки фиксируются отдельно
после их получения; этот документ сам по себе не подтверждает публикацию.
