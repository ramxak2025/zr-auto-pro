# Кнопка «Касса»: событие `onPress` конфликтовало с зарезервированным `topPress`

**Дата:** 26.07.2026
**Затронуто:** `mobile/modules/autexa-liquid-glass/ios/AutexaKassaButtonView.swift`, `.../ios/AutexaLiquidGlassModule.swift`, `.../src/AutexaKassaButton.tsx`

## Проблема

Дев-сборка падала белым экраном сразу после входа:

```
Render Error
Event cannot be both direct and bubbling: topPress
  AutexaKassaButton.tsx (51:28)
  NativeViewManagerAdapter.native.tsx:120
```

Нативное вью центральной кнопки объявляло `Events("onPress")`. React Native резервирует `topPress` (то есть проп `onPress`) как **всплывающее** событие любого `View`, а Expo регистрирует события модуля как **прямые**. Одно имя в двух ролях — RN отказывается собрать конфиг вью.

## Почему это не всплывало раньше

Проверка стоит внутри `if (__DEV__)` в [ReactNativeViewConfigRegistry.js:40](../../mobile/node_modules/react-native/Libraries/Renderer/shims/ReactNativeViewConfigRegistry.js) — в релизных сборках её нет вообще. Поэтому TestFlight и App Store работали, а дев-сборка умирала. Дев-сборку этого проекта долго никто не запускал: приёмка шла релизными сборками на физическом устройстве, а первая дев-сборка 26.07 падала ещё раньше — на неслинкованном `react-native-keyboard-controller` (нативная часть была от 28 июня, пакет добавлен 11 июля). Мина лежала тихо.

## Решение

Событие на границе с нативом переименовано в `onKassaPress` — в трёх местах: `EventDispatcher` во вью, `Events(...)` в объявлении модуля, тип и проп в TS-обёртке. **Публичное свойство компонента осталось `onPress`**, поэтому вызывающий код (таб-бар) не тронут вовсе. В каждое из трёх мест положен комментарий с причиной, чтобы имя не «починили» обратно.

Занятая RN номенклатура — только `onPress`; соседнее `Events("onTabPress")` у таб-бара даёт `topTabPress` и ни с чем не конфликтует, его не трогали.

## Проверено

- `expo prebuild --platform ios --clean` + `pod install` (114 зависимостей, 123 пода) + `xcodebuild` → **BUILD SUCCEEDED**;
- в симуляторе (iPhone 17 Pro, iOS 26.4.1): приложение открывается, дашборд рисуется, красного экрана нет;
- кнопка «Касса» не только отрисовалась, но и **сработала** — тап открыл экран заказ-наряда, значит событие доходит от Swift до JS под новым именем;
- `typecheck`, `lint` чисто, 623 теста в 33 сьютах зелёные.
