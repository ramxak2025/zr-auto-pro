Это нужно проверить на iPhone 17 Pro владельца.

## Известные ограничения

- Persistence не покрывает 100% запросов — только PERSISTED_KEYS (products, services, users, schedule, caching for-check).
- При первом логине после установки — кеша нет, спиннер на Dashboard будет (но prefetch начнётся параллельно).
- При смене API URL (например `autexa.pw` → другой) — старый кеш может содержать stale данные. Очистка через logout (logout очищает AsyncStorage).
