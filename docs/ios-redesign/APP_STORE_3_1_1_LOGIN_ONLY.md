# App Store Guideline 3.1.1 — iOS переведён в login-only (2026-07-09)

## Проблема (причина отказа App Review)

Сборка iOS (v3.0.0, build 49) была **отклонена** по **Guideline 3.1.1 (Business → Payments → In-App Purchase)**.

Причина, названная владельцем: в приложении есть **кнопка «Регистрация»**, а подписка оплачивается **вне Apple** (лично / на стороне SaaS-владельца, без Apple In-App Purchase). Apple запрещает создавать в приложении аккаунт, который открывает доступ к платной подписке, оплачиваемой мимо IAP, и запрещает любые CTA/ссылки, ведущие к оплате вне Apple.

Подтверждено по актуальным (2026) гайдлайнам: для бизнес-приложения, чья подписка биллится снаружи, надёжный путь — **login-only / «reader-app» паттерн**: приложение пускает **существующих** пользователей войти и управлять аккаунтом, но **не** предлагает регистрацию, ведущую к платному контенту, и **не** содержит кнопок/ссылок/текста, направляющих на внешнюю покупку.

Источники: Apple App Review Guidelines (developer.apple.com/app-store/review/guidelines/), BuddyBoss 3.1.1 guide.

## Выбранный путь

- **Подход:** login-only (внешняя оплата сохраняется, Apple комиссию НЕ берёт). Apple IAP сознательно НЕ подключаем — владелец биллит подписку лично.
- **Регистрация на iOS:** убрана полностью. Новые автосервисы регистрируются на сайте `autexa.pw`. Демо-доступ на экране входа сохранён (нужен App Review).
- **Область:** все правки **только для iOS** (`Platform.OS === 'ios'` / `isIos`). **Android и web — байт-в-байт без изменений** (Android распространяется через APK-сайдлоад, Google Play на паузе; там WhatsApp-CTA продаж остаются).

## Fallback / поведение на других платформах

- Android: JS-ветки `!isIos` рендерят прежний UI — регистрация, цены, WhatsApp-оплата. Ничего не потеряно.
- Web: не затронут (правки в `mobile/` файлах).
- Старые iOS-сборки, уже установленные: не важно — App Review ревьюит бинарь новой сборки.

## Acceptance criteria (как проверяет владелец на iPhone)

1. Экран входа: **нет** кнопки «Регистрация», есть «Войти» + демо-доступ. Существующий аккаунт логинится как раньше.
2. Открыть заблокированную по тарифу фичу: показывается плашка без цены, без «Перейти на тариф», без WhatsApp — только нейтральный текст.
3. «Ещё → Подписка» (директор): виден текущий тариф + дата, **нет** цен и списка покупаемых тарифов, **нет** кнопок оплаты.
4. Истёкшая подписка: экран без цены продления и без «по вопросам оплаты» — «Связаться с нами» + «Проверить статус».
5. Баг, если: где-то на iOS всё ещё видна кнопка/ссылка/текст, ведущие к оплате подписки вне Apple, либо возможность создать аккаунт.

## Следующие шаги (релиз)
