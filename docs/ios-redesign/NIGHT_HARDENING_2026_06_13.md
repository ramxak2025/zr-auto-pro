# Ночное продакшен-укрепление — 2026-06-13

Жалобы владельца после теста build 9 на физическом iPhone: под мастером всё медленно и с ошибками («перезагрузить» — потом работает); виджет мастера показывает прибыль вместо зарплаты; Склад — вечная загрузка; Клиенты всё ещё дёргаются при скролле; Учебный центр не работает; База знаний «то пусто, то есть». Требование: продакшен-качество для всех ролей, мгновенные актуальные данные, затем TestFlight + APK.

Методика: живые curl-пробы прода под ролями director/master (demo-тенант) → точные корни → 6 параллельных лайнов с обязательными file:line-доказательствами.

## Доказанные корни и лечение

1. **Учебный центр (500 на каждый запрос).** `knowledge.service.ts` listCourses: 3 bind-параметра при SQL, ссылающемся только на `$1`/`$3` → Postgres 42P18 на Parse. Детерминированно для всех ролей/тенантов. Исправлено; свип всех ~35 запросов модуля — других экземпляров нет. (`backend`, миграция 069 с hot-path индексами: products(tenant,warehouse,name), GIN-trigram barcode, schedule_entries(tenant,date).)

2. **«То пусто, то показывает» (База знаний и не только).** Гонка клиентского ETag-кеша: login-фан-аут > LRU-100 вытеснял тело между отправкой If-None-Match и приходом 304 → пустые данные уходили в React Query и persist. Теперь 304 без тела прозрачно перезапрашивает полный ресурс; etag+тело — одна запись; пустота физически не может дойти до кеша. Плюс на 7 KB-экранах ошибка больше никогда не рендерится как «Пока пусто» (везде QueryErrorState с «Повторить», offline-пауза → скелетон).

3. **Мастер: медленно + «ошибка → повторить»**. (а) retry:1 на ВСЁ, включая 403/400 → до 20с спиннеров на запросах, которые не могут успеть; теперь 4xx не ретраятся вовсе. (б) prefetch и pull-to-refresh дёргали владельческие ключи (8 эндпоинтов /reports/\* отдают мастеру 403 — проверено живьём) и мёртвый ключ checks-dashboard; вычищено, под мастером 403 не летят вообще. (в) единственный error-стейт мастерского дашборда был тупиковым `<Text>` без ретрая — теперь QueryErrorState.

4. **Виджет мастера показывал прибыль.** Сама привязка master→/salary/my была корректной; баг — App Group payload не очищался при logout/смене роли, и виджет держал владельческие цифры прошлой сессии (а старые сборки писали их без role). Добавлен clearWidgetData() на logout/401/login + sentinel «Откройте Autexa» в Swift.

5. **Склад — вечная загрузка.** Три клиентских тупика: deadlock enabled-гейта при `warehouses=[]`; «ошибка холодного фетча → вечный скелетон без ретрая»; пустой лист пикера Кассы при ошибке. Все ветки теперь оканчиваются контентом/EmptyState/QueryErrorState. Бонус: первый открыв пикера — мгновенный кеш-хит (placeholder-мост скоупнутого ключа главного склада к прогретому нескоупнутому).

6. **Клиенты дёргаются (после первого фикса).** Глубокий корень: легаси class-Swipeable в recycling FlashList v2 — `reset()`/onLayout делают setState на каждый recycle, а native-driver transform на Fabric держит сдвиг предыдущей строки до JS-раундтрипа → строки «прыгают и пропадают». Заменён на ReanimatedSwipeable (RNGH 2.28, UI-thread shared values, reset без setState); мемоизирован contentContainerStyle (терял идентичность при каждом isFetchingNextPage). Эталон — беспроблемный Журнал (там нет gesture-обёрток на строках).

7. **Свежесть данных.** setQueryDefaults: staleTime 30с для горячих ключей (журнал/склад/клиенты/дашборд/расписание/поставщики) при глобальных 2мин — отрисовка мгновенно из кеша, ревалидация в фоне при навигации/фокусе.

## Ограничения

- Серверных логов нет (SSH к VDS не настроен) — диагностика через живые пробы demo-тенанта; на тенанте владельца объёмы больше, индексы миграции 069 целят именно туда.
- На устройстве не запускалось (правило владельца) — компиляция/линт/тесты + curl-верификация.

## Приёмка владельцем (iPhone, build 10)

1. Под мастером: вход → дашборд мгновенно из кеша; никаких «ошибка/повторить» при сети; в Чарльз/прокси — ни одного 403.
2. Склад: открыть в авиарежиме с холодным кешем → карточка ошибки с «Повторить» (не вечный скелетон); с сетью — мгновенно.
3. Клиенты: режим «по клиентам», быстрый скролл — ровно; свайп работает.
4. Учебный центр: открывается (после деплоя backend); База знаний — «пусто» только когда реально пусто.
5. Виджет: владелец — оборот/прибыль; выход → «Откройте Autexa»; вход мастером + открыть дашборд → «Мой заработок».
