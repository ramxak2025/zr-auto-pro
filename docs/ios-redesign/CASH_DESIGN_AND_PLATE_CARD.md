# Касса — карточка клиента и госномер

## Поведение

**Клиент НЕ выбран** — показывается поиск:

- Лейбл «ПОИСК ПО ГОСНОМЕРУ» + RU/INT switcher
- `RussianPlateInput` (контролируемый)
- Live-результаты под полем (после 2+ символов)
- «Клиент не найден» — только когда поиск завершён, без преждевременного flash
- «Розничный покупатель» — fallback-карточка снизу

**Клиент выбран** — поиск полностью скрыт, на его месте `selectedCard`:

- Аватар (44pt круг)
- Имя клиента + телефон
- Кнопка ✕ (top-right, 32pt серый круг, hitSlop 12pt)
- Hairline-разделитель
- Госномер (`PlateBadge`) + makeModel + comment
- Селектор сиблингов-машин — только если у клиента 2+ авто

Реализовано в `mobile/src/screens/CheckCreateScreen.tsx`.

## Государственный номер РФ

Точные пропорции по ГОСТ Р 50577-93:

| Параметр           | Значение                  |
| ------------------ | ------------------------- |
| Соотношение сторон | 4.64 : 1                  |
| `PLATE_HEIGHT`     | 48pt                      |
| `PLATE_WIDTH`      | 223pt                     |
| `PLATE_REGION_W`   | 48pt (square right strip) |
| `PLATE_MAIN_W`     | 173pt (78%)               |
| Inner cant inset   | 3pt (hairline)            |

### Левый блок

- 1 буква + 3 цифры + 2 буквы (`formatMain`)
- Шрифт 26pt, weight 800, letter-spacing 1.6
- Регион здесь **никогда не дублируется** (в прошлом был баг
  `О 777 ОО 88 | 88` — устранён выделением региона в `splitPlate`).

### Правый блок (район региона)

Точно по референсу из задачи:

```
┌─────────┐
│   198   │   ← regionText: 22pt, weight 800
│ RUS 🇷🇺  │   ← rusFlagRow: row {RUS + flag-box}
└─────────┘
```

- `regionText` — 22pt bold, lineHeight 24
- `rusFlagRow` — `flexDirection: row`, gap 2
- `rusLabel` — «RUS» 8pt 900-weight
- `flagBox` — 12×6.6pt (3 горизонтальные полосы 12×2.2pt)
- Полосы: `#FFFFFF` / `#0039A6` / `#D52B1E` (точные ГОСТ цвета)
- Тонкая чёрная hairline-обводка вокруг флага

### Иностранный номер (INT)

- Если `isRussianInput(clean)` = false → `frameForeign` с синим бордером
- Слева вертикальный синий стрип «INT»
- Текст монолитом без российской маски

## Нормализация

`mobile/src/utils/plateMask.ts`:

- `latinToCyrillic` — A→А, B→В, E→Е и т.д.
- `toUpperCase` для всех букв
- Удаление пробелов, дефисов, прочих символов
- `splitPlate` — отделяет main от region
- Поиск выполняется по нормализованной строке (`normalizedSearch`)
