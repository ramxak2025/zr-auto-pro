# Рефакторинг 19 мая 2026

Большой пасс по визуалу и UX мобильного клиента (iOS + Android — общий JS, нативный код не трогался). Все изменения — на ветке `refactor/full-audit-2026`, запушены.

## Что сделано — 8 коммитов

### 1. Tab-bar overlap fix на 15 экранах + унификация хедеров
**Коммит:** `83c62cb fix(ios): tab-bar overlap on 15 screens + unify ClientDetail/Admin headers`

Все экраны под Floating Liquid Glass tab bar'ом подрезали последний элемент списка под полоской (`paddingBottom: spacing[8]` ≈ 32 pt при реальной высоте бара ~110 pt). Переведены на `useTabBarHeight()`:
Salary, CompanySettings, Reports, Marketing, Subscription, Cars, Clients (2 FlashList), Expenses, CashFlow, Admin, Equipment (4 ScrollView), Trash, Users, Suppliers (+ scrollIndicatorInsets), Services. ScheduleScreen — все 4 вкладки получили собственный hook-call.

ClientDetailScreen + AdminScreen использовали свои bespoke хедеры — мигрировали на общий `IosScreenHeader`. `showDivider=false` теперь реально убирает hairline.

### 2. Splash без сине-белого скачка
**Коммит:** `ae6eb37 fix(splash): remove blue→white jump by syncing OS splash with overlay`

Native splash красил `#2563eb` (синий с логотипом), затем RN overlay рисовал `#f9fafb` (white) — заметный flash. Сменили native splash на тот же gray-50 + transparent logo.png. SplashOverlay получил `FadeOut.duration(240)` для плавного dismissal'а и logo подогнан к 280×73 для совпадения позиции.

**ВАЖНО:** для применения native splash bg нужен `expo prebuild --platform ios --clean && pod install` + новый Release. JS-часть (логика fade-out) работает сразу.

### 3. Schedule — полностью залитые карточки с эмодзи
**Коммит:** `f8a72fc feat(schedule): full-colored status cards with emoji on Today tab`

Today-карточки были маленьким цветным кружком на белом — теперь карточка целиком в семантичном оттенке + эмодзи + крупный лейбл:
- 🤒 Больничный (rose)
- 😴 Выходной (gray)
- 🚨 Опоздание >1ч (orange)
- ⏰ Опоздание <1ч (yellow)
- ✅ На смене (green)
- ❌ Прогул (red)
- ➖ Нет смены (gray)

Имя сотрудника, время смены, время прихода — всё в едином тоне статуса. 1pt тонированная граница вместо тяжёлой тени.

### 4. Clients — Apple Contacts-style плотный список
**Коммит:** `d320d67 feat(clients): iOS Contacts-style dense list with avatar initials`

Двухстрочные карточки с действиями превратились в плотный 56pt-row: 40pt аватар-кружок с инициалами в детерминированной палитре, имя 15pt semibold, sub-line "телефон · N авто", chevron справа. Edit/Delete — через свайп влево (паттерн SuppliersScreen), gated по правам. Pinned "Розничный покупатель" сохранил branded storefront-иконку.

### 5. Equipment — 2×N сетка фото-карт + page-sheet модалка
**Коммит:** `ed09478 feat(equipment): 2-col photo-card grid + pageSheet issue modal`

Сотрудники теперь рендерятся как 2 карточки в ряд, aspect 0.82:
- Фон — фото сотрудника или primary 500→700 gradient с большими инициалами при отсутствии фото
- Нижний dark gradient (0 → 0.65 → 0.85) для читаемости белого текста
- Стоимость имущества — герой 18pt 800-weight
- Top-right amber-пилл с количеством просрочки

IssueModal переведена с full-screen `slide` на `presentationStyle="pageSheet"` — теперь это нативный iOS bottom sheet с swipe-to-dismiss, не лезет под Dynamic Island. Все функции (выдача со склада, фото, категории) сохранены.

### 6. CheckCreate — компактный хедер + чище placeholder
**Коммит:** `7178ee5 feat(check-create): compact receipt header + clearer comment placeholder`

72pt-полоса "ЗАКАЗ-НАРЯД" сжата в ~40pt single-line: "ЗАКАЗ-НАРЯД · Новый чек" (или "Редактирование"), 12pt с letter-spacing 2. Освободило ~30pt для тела чека. Placeholder комментария: "Комментарий или рекомендация клиенту по чеку" — короче и понятнее.

### 7. Dashboard — tap-to-detail sheet
**Коммит:** `426b947 feat(dashboard): tap-to-detail sheet on chart points`

Тап по любой день-карточке под графиком открывает bottom sheet с полной картиной:
- Дата длинной формой ("Понедельник, 14 апреля 2026 г.")
- Оборот · Прибыль (большие box'ы)
- Чеков · Средний чек
- Дельта vs предыдущего периода — 3 цветных ↑/↓ % пилюли (revenue, profit, checks)

Backend уже возвращал `checkCount` per-point — без правок API.

### 8. Brand-tinted Skeleton
**Коммит:** `3889c0a feat(skeleton): brand-tinted shimmer placeholder`

Skeleton-плейсхолдер был нейтрально-серым — теперь подложка `#eaf1fb` (производное от primary[50]) и шиммер с тонкими брендовыми оттенками по краям. ~12 экранов получили унифицированный "Autexa загружается" вид.

## Что НЕ сделано (и почему)

### Android Material 3 адаптация
**Почему:** Большая часть приложения уже работает кроссплатформенно. Material-специфичные ripple/elevation/icons требуют отдельного аудита по каждому экрану. Текущий приоритет — iPhone (рабочее устройство владельца), поэтому отложено как follow-up.

### Backend pagination для чеков и оптимизация поиска (debouncing)
**Почему:** Backend уже отдаёт `{ data, total, page, limit }`, mobile уже использует `useInfiniteQuery` с `onEndReached`. Skeleton при cold-start есть. SearchInput уже debounced на 250 ms. Дополнительная работа не нужна.

### "Фейковые нули и рандомные цифры на этапе загрузки"
**Почему:** Сделан выборочный аудит — нашёл только два места с `placeholder="0"` (CheckCreateScreen числовые поля количества/цены — это нормальные input placeholders, не фейк-данные). Глобальных фейк-нулей в карточках статистики не обнаружено — всё уже идёт через skeleton при `data === undefined`.

### Native iOS swipe-back
**Почему:** Уже работает. `createNativeStackNavigator` (iOS) использует UINavigationController, который даёт edge-swipe по умолчанию. `gestureEnabled: false` нигде не выставлен. `IosScreenHeader` не перехватывает свайп-зону.

### Удалить старый `assets/splash.png`
**Почему:** Файл больше не используется (заменён на `logo.png`), но я не стал его удалять чтобы не получить мёртвую ссылку при `expo prebuild`, если кеш Expo ещё помнит старый путь. Можно удалить отдельным mini-commit'ом после успешного билда.
